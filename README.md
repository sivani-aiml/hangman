# Hangman Game 🎯

A simple command-line Hangman game built with Python.

## About

This project is a Python implementation of the classic Hangman word-guessing game. The player tries to guess the hidden word one letter at a time before running out of lives.

## Features

* Random word selection
* ASCII art hangman stages
* Life tracking system
* Win and lose conditions
* Console-based gameplay

## Technologies Used

* Python 3

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/sivani-aiml/hangman.git
   ```

2. Navigate to the project folder:

   ```bash
   cd hangman
   ```

3. Run the game:

   ```bash
   python main.py
   ```
